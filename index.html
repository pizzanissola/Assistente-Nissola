2. Cadastro de preços de compra

Informe o preço pago e o conteúdo total da embalagem. Ex.: pacote de muçarela com 1.000 g custando R$ 38,00. O app calcula o custo por grama e atualiza todas as pizzas automaticamente.

Os valores que aparecem primeiro são apenas referências iniciais para preencher a tela. Substitua-os pelos preços das suas notas fiscais e inclua frete ou perdas no custo quando necessário.

+ Cadastrar novo insumo

Cadastre aqui ingredientes que ainda não existem, como camarão e gorgonzola. Depois eles ficam disponíveis para qualquer ficha técnica.

3. Ficha técnica do sabor selecionado

Altere a quantidade de cada ingrediente por pizza. Para ingredientes sólidos, use gramas; para massa, use unidade. O custo dos ingredientes é recalculado a partir dos preços de compra cadastrados.

Use “Remover da ficha” em cada ingrediente que não compõe esse sabor. Remover da ficha não apaga o insumo do cadastro geral.

Nuvem e backup

Conecte sua conta Google para guardar um backup JSON no seu Google Drive. A primeira configuração exige um ID OAuth do Google Cloud e que este app esteja publicado em um endereço HTTPS autorizado.

O ID do cliente não é sua senha. Nunca cole aqui um segredo de cliente OAuth.
Status da nuvem
Não conectado
Os dados continuam salvos neste aparelho.
A conexão não fica ativa automaticamente depois que você fecha o navegador. Ao abrir o app em outra sessão, conecte novamente e escolha restaurar ou salvar. Antes de restaurar, o app pedirá confirmação porque os dados locais serão substituídos.

Configuração inicial do Google

  1. Publique o app em um endereço HTTPS (por exemplo, hospedagem estática).
  2. No Google Cloud Console, crie um projeto, habilite a Google Drive API e configure a tela de consentimento OAuth.
  3. Crie um ID de cliente OAuth do tipo Aplicativo da Web e adicione o domínio publicado em “Origens JavaScript autorizadas”.
  4. Cole o ID de cliente acima e toque em “Conectar Google Drive”.

Como usar os custos corretamente

CMV: custo dos ingredientes usados na pizza ÷ preço de venda. Margem de contribuição: preço menos ingredientes, embalagem, energia e taxas variáveis. O valor restante ajuda a pagar despesas fixas e depois gerar lucro.

O app guarda os dados no armazenamento local do navegador deste aparelho. Exporte o CSV periodicamente como cópia. Se limpar os dados do navegador ou mudar de aparelho, restaure os valores usando o backup exportado/manual.
